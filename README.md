# Zscaler Labs: ZIA & ZPA

Notes on Zscaler Internet Access (ZIA) and Zscaler Private Access (ZPA), based on my work with both. This repo is a work in progress.

## Topics

**ZIA**
- URL filtering and access policies
- SSL inspection, including bypass rules and certificate handling
- Migrating users from a legacy proxy (Blue Coat ProxySG) to Zscaler

**ZPA**
- Application segments and segment groups
- Access policies for private applications (least-privilege ZTNA)
- App Connector basics

**Identity and troubleshooting**
- SAML/SSO integration with Azure AD
- Zscaler Client Connector: authentication, connectivity and policy troubleshooting

## Status

The repo currently contains this README and a license. Notes will be added under `zia/`, `zpa/`, `identity/` and `troubleshooting/` as I write them. Nothing here includes tenant IDs, policy names or other organization data.
